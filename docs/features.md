# Hearth — Feature List

## Core (MVP)

- **Channels** — Named rooms, visible to all members
- **Messages** — Real-time posting and display in channels
- **Persistent history** — Full message history retained indefinitely (key differentiator from free Slack)
- **User accounts** — Registration, login, profile (name, avatar)
- **Mentions** — `@username` notifications
- **Basic formatting** — Markdown or a lightweight subset (bold, italic, code, links)

## Communication

- **Direct messages** — Private 1:1 conversations
- **Group DMs** — Private multi-user conversations
- **Threads** — Replies scoped to a specific message
- **Reactions** — Emoji responses to messages

## Content

- **File uploads** — Images and documents shared in channels/DMs
- **Link previews** — Unfurled URLs with title/description/image
- **Code snippets** — Syntax-highlighted code blocks

## Discovery & Navigation

- **Search** — Full-text search across message history
- **Pinned messages** — Highlight important messages in a channel
- **Channel bookmarks** — Save links or resources at the top of a channel

## Presence & Notifications

- **Online presence** — Show who is active
- **Notifications** — In-app alerts for mentions and DMs
- **Email digest** — Summary of missed activity

## Administration

- **Channel management** — Create, archive, set topic/description
- **Member management** — Invite, remove, roles (admin vs member)
- **Invite links** — Shareable signup links for the group

## Possible Differentiators

Features Slack does poorly or locks behind paid tiers that we could do better:

- **Unlimited history** — Free Slack caps at 90 days
- **No message limits** — Free Slack caps at 10k searchable messages
- **Open source / self-hosted** — Full control, no vendor lock-in
- **RSS/webhook feeds** — Pipe external content (GitHub, meetup announcements) into channels
- **RSVP / event threads** — Lightweight event coordination built into a channel
- **Polls** — Simple voting in a channel
